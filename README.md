Projeto desenvolvido para praticar lógica de programação com Python. O programa recolhe informações sobre a satisfação dos cliente sobre o atendimento da empresa. Coleta dados, como **nome**, **idade** e **grau de satisfação**. Após apresenta a quantidade de votos de pessoas por grau de satisfação em **excelente** e **ruim**

---

#  🎯 Objetivo do Programa 

* Desenvolver um algoritmo para coletar dados dos usuários e sua satisfação com a empresa.
* Praticar o ciclo Entrada → Processamento → Saída: receber o tipo de imóvel e a quantidade de água utilizada mensalmente (m³), analisar as informações e informar o tipo de consumo.
receber o nome, idade e grau de satisfação, contar a quantidade de votos e apresentar o grau de satisfação excelente e ruim.
* Utilizar estrutura de repetição `for` para realizar a pesquisa com 50 clientes e a estrutura de decisão `if/else` para analisar os dados.

---

## 📋 Condições da Pesquisa

| Informação | Descrição |
|---|---|
| Número de clientes | 50 |
| Dados coletados | Nome, idade e grau de satisfação |
| Opções de satisfação | Excelente, Bom ou Ruim |
| Resultado apresentado | Quantidade de respostas Excelente e Ruim |
